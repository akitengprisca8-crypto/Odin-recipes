
Odin Recipes

This project is a basic recipe website created as part of The Odin Project curriculum.

The website contains an index page that links to several recipe pages. Each recipe page includes an image of the finished dish, a description, a list of ingredients, and step-by-step cooking instructions.

Skills Demonstrated

By completing this project, I will demonstrate my ability to:
Create and structure HTML documents.
Use headings, paragraphs, images, links, and lists.
Create multiple pages and link them together.
Organize files and directories in a web project.
Use Git to track changes.
Create and manage a repository on GitHub.
Clone a remote repository using SSH.
Commit and push project changes to GitHub.

This project will help reinforce the basic HTML and Git skills I have learned so far in The Odin Project.
